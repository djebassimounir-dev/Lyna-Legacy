\subsection{Abstract \& Overview}\label{abstract-overview}

This notebook contains the complete, reproducible computational pipeline
for analyzing 175 galaxy rotation curves from the \textbf{SPARC}
(Spitzer Photometry and Accurate Rotation Curves) dataset. It evaluates
the empirical performance of the \textbf{Baryonic Valve}
phenomenological model (\(V_{\text{eff}}^2\)) and investigates its
asymptotic divergence from the \textbf{Baryonic Tully-Fisher Relation
(BTFR)}.

\subsubsection{Model Equations}\label{model-equations}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Effective Velocity:}
  \[V_{\text{eff}}^2(r) = V_{\text{bar}}^2(r) + B_0^2 \frac{\exp(-\eta(r))}{\eta(r)}\]
\item
  \textbf{Dimensionless Relaxation Parameter:}
  \[\eta(r) = \frac{l(r)}{r} = \frac{l_0}{V_{\text{bar}}^2(r) \cdot r}\]
\item
  \textbf{Asymptotic Slope Derivation:}
  \[\frac{d\ln V_{\text{flat}}}{d\ln M} = \frac{1+\eta}{2} \xrightarrow{\eta \ll 1} 0.50 \quad (\text{vs. BTFR observational requirement } \approx 0.25)\]
\end{enumerate}
